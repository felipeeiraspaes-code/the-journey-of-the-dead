# The Journey of the Dead

A small browser survival game built with vanilla HTML, CSS, and JavaScript.

## How to play

1. Enter your name.
2. Survive 10 days, with three encounters per day.
3. Choose whether to fight or run from each encounter.
4. Manage health, hunger, thirst, and combat strength.

## Project structure

The game is currently intentionally self-contained in index.html, so it can be published directly with GitHub Pages.

## Development

Open index.html in a browser or serve the repository with any static web server. There is no build step or dependency installation required.
